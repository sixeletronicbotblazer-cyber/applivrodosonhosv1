# Pacote de construção do aplicativo

1. Abra `previa_cinco_telas.png` para ver a direção visual e as cinco imagens separadas em `telas/`.
2. Envie ao Z.ai o PDF original do livro, `DESIGN.md`, `BANCO_DE_DADOS.md`, `schema.sql`, os dois JSON e as cinco telas.
3. Cole `COMANDO_MASTER_ZAI.md` integralmente.
4. Antes de publicar, confira todos os dados OCR no PDF pelo painel de revisão, cadastre IDs reais das ofertas e configure e-mail OTP e webhook de pagamento.

Conteúdo: 538 registros extraídos automaticamente + 538 registros editoriais/de busca = 1.076 registros **de trabalho**. Não corresponde a 1.076 verbetes literais validados. O PDF é fornecido separadamente para reduzir o ZIP; adicione-o no construtor.

As cinco telas são mockups PNG em 1170×2532 px, com a capa original do livro numa delas. Os scripts de geração estão incluídos para manter os materiais editáveis. A imagem 04 usa o exemplo Cavalo conferido na página 46 do PDF.
